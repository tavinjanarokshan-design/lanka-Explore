About the project

About Us

Lanka Explorer is a solo mini project by ROKSHAN TAVINJANA. It helps travellers compare Sri Lankan destinations, check live weather and maps, convert entry fees into rupees, and assemble a saved trip budget. The site was built in five weekly stages, from semantic HTML to API integrations and browser storage.
